# Procesos operativos

Objetivo: que **cualquier miembro del equipo** pueda operar la tienda sin depender de una sola persona.
Cada proceso tiene su guía escrita y un video corto (≈5 min) en Drive → `ESCAPE NATIVO/Web BackUps/DEMOS/`.

Los pasos están escritos para WordPress + WooCommerce estándar y están marcados 🟡 hasta
verificarlos contra el sitio real y el video correspondiente.
