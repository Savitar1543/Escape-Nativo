# Publicar en el blog

| Estado | Rol mínimo | Video |
|---|---|---|
| 🟡 por verificar | Editor / Autor | `DEMOS/Nota HTML.mov` |

## Pasos

1. `wp-admin` → **Entradas → Añadir nueva**.
2. Título claro (≤ 60 caracteres para SEO).
3. Cuerpo con bloques; si se pega HTML, usar el bloque **HTML personalizado**.
4. **Imagen destacada** con texto alternativo.
5. Categoría y etiquetas.
6. Extracto / meta descripción (≤ 155 caracteres), que mencione Mogotes, Santander cuando aplique.
7. **Vista previa** en celular → **Publicar**.

Revisar el texto contra la lista negra de [sistema-de-marca.md](../marca/sistema-de-marca.md).
