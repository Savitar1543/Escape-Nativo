# Registro de decisiones (ADR)

Cada decisión que cambia el sitio o la forma de trabajar se registra en un archivo
`NNNN-titulo-corto.md` con este formato:

```markdown
# NNNN. Título

- Fecha: AAAA-MM-DD
- Estado: propuesta | aceptada | reemplazada por NNNN

## Contexto
## Decisión
## Consecuencias
```

| [0002](0002-datos-estructurados.md) | Corregir datos estructurados de productos | Propuesta |
| [0003](0003-flujo-home.md) | Nuevo flujo del Home (7 secciones) | Aceptada |
