# Impacto Nativo

| Campo | Valor |
|---|---|
| Ruta | `/impacto-nativo/` |
| Estado | Privada, lista para publicar (visible en el menú solo para administradores) |
| Posición en el menú | `Inicio | Café | Nuestra Historia | Impacto Nativo | Contacto` |

## Contenido

- Capítulos de impacto.
- **«Trueque que Transforma».**
- Formulario de beca.

## Criterios de aceptación

- [ ] Diseño terminado
- [ ] Texto cargado
- [ ] 10 fotografías
- [ ] Formulario de contacto/beca funcionando (envío probado)
- [ ] Optimizada para celular
- [ ] Optimizada para SEO (título, meta descripción, imagen OG)

## Para publicar

1. Revisar la checklist.
2. Cambiar la visibilidad de *Privada* a *Pública*.
3. Mostrar el ítem en el menú para todos los visitantes.
4. Actualizar el [árbol de navegación](../arquitectura/arbol-navegacion.md).
